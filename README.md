# QueueFlowDB

A database engineering project for designing and implementing a queue-based database system using SQL Server and MongoDB.

## Technology Stack
- SQL Server
- MongoDB
- Python
- Git and GitHub

## Project Structure
- docs/ – Project documentation and ER diagrams
- sql/ – Database schema, queries, and scripts
- mongodb/ – MongoDB collections and operations
- src/ – Application source code
- tests/ – Test cases

## Development Methodology
This project is developed using Agile Scrum with Jira sprint planning and task tracking.
